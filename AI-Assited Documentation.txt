Choose at least 3 parts of the AI-generated code and explain what they do:
1. <article>: This is a semantic HTML5 element. It tells web browsers and search engines that the content inside it is independent, self-contained, and could logically stand alone or be reused (like a forum post, magazine article, or product card).
2. <footer>: This is a semantic HTML5 element. It designates the footer area of a webpage or section. It usually contains metadata, copyright information, contact links, or privacy policies.
3. <address>: This is a semantic HTML5 element. It indicates that the enclosed HTML provides contact information for the nearest ancestor <article> or <body> element. Browsers typically display the text inside this tag in italics by default.
